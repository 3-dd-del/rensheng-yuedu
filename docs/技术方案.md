# 人生阅读 · MVP 技术方案（v0.1）

- 关联文档：[产品设计文档](../产品设计文档.md)
- 日期：2026-09-08
- 状态：初稿，待评审

## 1. 目标与范围

实现「本地优先的个人电子阅读器」MVP：浏览器中导入并阅读中文 TXT 大文件，翻页流畅、断点续读准确，全程本地使用。

第一版不包含：账号与云同步、EPUB/PDF、书签划线、章节目录、暗色模式、全文搜索、AI 辅助等。

## 2. 已确认的产品决策

1. 产品形态：纯本地网页版，浏览器中使用，不需要 Electron/Tauri 或安装包；
2. 阅读交互：翻页式阅读，非连续滚动；
3. 键盘快捷键：阅读器常用操作可全键盘完成；
4. 桌面入口：双击桌面图标，用默认浏览器打开阅读器；
5. 重复导入：按内容指纹识别同一文件，已存在时直达该书，不产生重复条目。

## 3. 技术栈总览

| 层面 | 选型 | 说明 |
| --- | --- | --- |
| 语言 | TypeScript | 全项目统一使用，降低长期维护成本 |
| 前端框架 | React | 与 TypeScript 生态成熟，组件拆分适合书架/阅读页 |
| 构建 | Vite | 开发热更新快，产物为纯静态资源 |
| 本地存储 | IndexedDB（Dexie 封装） | 保存书籍内容、进度、设置；容量足够且支持大文本 |
| 编码检测 | BOM 判断 + 严格 UTF-8 校验 + jschardet 启发式探测 | 覆盖 UTF-8/UTF-16/GBK/GB18030 常见情况 |
| 字符解码 | 浏览器内置 TextDecoder（含 gb18030） | 无需引入重解码库 |
| 分块与排版 | 自研分页引擎（隐藏容器测量 + 分块缓存） | MVP 最核心的技术工作，详见 §5.2 |
| 快捷键 | 自研轻量键盘监听（custom hook） | MVP 只需内部快捷键，不需要三方库 |
| 本地服务 | Node 静态服务脚本 | 双击桌面入口时负责启动服务并打开浏览器 |
| 测试 | Vitest + React Testing Library；后期补 Playwright E2E | 见 §7 |

## 4. 总体架构

```
桌面图标 / 启动脚本
        │ 启动本地静态服务并打开默认浏览器
        ▼
浏览器（http://127.0.0.1:PORT）
        │
        ▼
React 单页应用
  ├─ 导入模块：文件 → 编码识别 → 解码 → 指纹 → 分块入库
  ├─ 书库模块：书架、删除、继续阅读
  ├─ 分页引擎：把长文本切分为「页」，缓存页边界
  ├─ 阅读会话：翻页、进度、续读
  ├─ 快捷键与设置
  └─ IndexedDB（Dexie）
```

设计原则：

- 数据层与界面层分离，存储、分页、进度逻辑不依赖 React；
- 未来的 Electron/Tauri 外壳、移动端包装均复用同一套核心逻辑；
- 大文件处理放在 Web Worker，避免导入与排版阻塞界面。

## 5. 关键技术设计

### 5.1 导入与编码识别

导入流程：

1. 用户选择或拖入 TXT 文件；
2. 文件以 ArrayBuffer 形式交给导入 Worker；
3. Worker 依次执行：
   - BOM 检查（UTF-8/UTF-16LE/UTF-16BE）；
   - 无 BOM 时先尝试严格 UTF-8 解码，失败则进入启发式探测（GBK/GB18030 等）；
   - 按探测结果用 TextDecoder 解码为统一 Unicode 文本；
4. 计算内容指纹（SHA-256，基于原始文件字节），与书库比对；
5. 指纹已存在 → 提示「书库已有此书」，直达该书；
6. 新书 → 把解码文本按固定大小分块写入 IndexedDB，同时记录总字符数等元数据；
7. 识别不确定或失败 → 进入手动编码选择界面，提供预览，确认后再导入。

导入后应用自行保管内部文本，后续阅读不依赖原始文件路径与编码。

### 5.2 大文件与翻页式排版（核心任务）

要点：

- 不得把整本书渲染进 DOM；
- 文本按固定字符大小分块存储（例如每块约 50–100 万字符），阅读时按需读取当前页附近的块，避免一次加载全书；
- 分页引擎负责把文本切分为视觉上的「页」：以当前页面尺寸与字号/行距为参数，把内容填入隐藏测量容器，通过二分逼近确定「恰好装满一页」的字符终点；
- 每页只记录起点字符偏移，按需渲染当前页文本；渲染完成后页面 DOM 很小，翻页手感不会随书变大而劣化；
- 页边界按「布局指纹 + 页码」缓存：布局指纹包含视口尺寸、字号、行距。用户再次打开同一本书、同一设置时可直接命中缓存，秒回上次位置；
- 字号/行距/窗口尺寸变化时，清空该布局指纹下的分页缓存并按需重建；
- 通过导入 Worker 在后台完成初始解码与分块入库，进度条展示导入过程。

进度跳转策略：

- 跳转到任意百分比时，先用已缓存页边界定位最近的页，再从该页向后逐页排版到目标偏移；首次全本精排成本高，故只精排到目标附近；
- 续读时优先恢复「上次页码 + 对应布局指纹」，布局未变则直接打开；布局变化再回退到字符偏移重新分页。

### 5.3 断点续读与数据模型

IndexedDB 主要表：

| 表 | 内容 |
| --- | --- |
| books | id、书名、原文件名、内容指纹、编码、总字符数、导入时间、最近阅读时间、上次阅读偏移 |
| chunks | bookId、序号、起始偏移、文本块 |
| pagination | bookId、布局指纹、页码、页起始偏移（缓存，可增量补充） |
| settings | 阅读设置（字号、行距等），全局生效 |

进度规则：

- 阅读位置一律用「相对文本开头的字符偏移」记录，跨文件版本稳定可解释；
- 翻页后防抖写库，同时在 `pagehide` / `visibilitychange` 时立即保存，避免中途关闭丢进度；
- 书架进度百分比 = 上次阅读偏移 / 总字符数。

### 5.4 键盘快捷键（MVP）

快捷键只在阅读器窗口/标签页处于焦点时生效，不做操作系统级全局快捷键。

建议默认键位：

| 场景 | 按键 | 动作 |
| --- | --- | --- |
| 书架 | Enter | 打开选中书 / 继续阅读 |
| 书架 | Delete | 删除选中书（需确认） |
| 阅读页 | ← | 上一页 |
| 阅读页 | → / Space | 下一页 |
| 阅读页 | Esc | 返回书架 |
| 阅读页 | S | 打开阅读设置 |
| 阅读页 | ? | 查看快捷键说明 |
| 阅读设置 | +/-（或 ↑/↓） | 调整字号，界面同步预览 |

实现要求：

- 输入框/弹窗获得焦点时快捷键不误触；
- 同一份键位表同时驱动界面按钮提示与帮助面板，避免两处不一致。

### 5.5 桌面入口

浏览器里使用的本地应用需要一个本地静态服务，方案：

- 构建产物为纯静态资源，启动脚本用轻量 Node 服务托管在 `http://127.0.0.1` 的固定端口；
- 桌面快捷方式指向启动脚本：若服务未启动则拉起（隐藏控制台窗口），等待健康检查通过后用 `start` 打开默认浏览器直达阅读器；
- 若服务已在运行，则直接打开浏览器，不重复启动；
- 关闭浏览器不会关闭服务；提供「退出」入口用于停止本地服务；
- 若后续需要更接近原生 App 的体验，可在不改动核心逻辑的前提下增量加入 PWA，或改用 Electron/Tauri 外壳。

注意：数据保存在浏览器与该本地地址绑定的存储中，因此 MVP 界面需提供书库「导出/导入」功能，便于换浏览器或清缓存前备份。

## 6. 目录规划（建议）

```
src/
  app/                  # 路由与页面：书架、阅读、导入
  features/
    import/             # 导入流程
    library/            # 书架与书籍管理
    reader/             # 阅读页、翻页、快捷键、设置
  core/
    storage/            # IndexedDB 数据层
    encoding/           # 编码识别与解码
    pagination/         # 分页引擎与页边界缓存
    progress/           # 进度存取
  workers/
    import.worker.ts    # 解码、指纹、分块入库
tests/                  # 单元与集成测试
```

## 7. 测试策略

- 单元测试（Vitest）：
  - 编码识别：UTF-8、UTF-8 BOM、UTF-16、GBK、GB18030 各用固定样本验证；
  - 分页：给定固定视口/字号样本，验证页边界不重叠、不漏字、末页正确；
  - 进度与续读：字符偏移存取、布局变化后的恢复逻辑；
  - 快捷键映射：焦点场景下不误触发。
- 集成测试（React Testing Library）：导入 → 书架 → 阅读 → 关闭 → 续读的完整链路。
- 性能测试：用几百万字真实样本验证导入耗时、打开耗时、连续翻页不掉帧；作为验收门槛写进测试。
- E2E（Playwright，功能稳定后补充）：真实浏览器中完成大文件导入与长距离进度跳转。

## 8. 里程碑建议

1. M1 项目骨架 + IndexedDB 数据层 + 导入管线（含编码识别）；
2. M2 书架与书籍管理；
3. M3 翻页式阅读 + 分页缓存 + 断点续读（核心验收）；
4. M4 阅读设置 + 键盘快捷键 + 快捷键帮助；
5. M5 桌面入口 + 书库导出/导入 + 性能打磨。
